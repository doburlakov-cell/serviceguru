# Макет №2: сайт, настроенный на заявки

Файл макета: `site-update/mockup-v2/index.html` (рядом лежит `standalone.html`, он открывается прямо в браузере).

## Про цель «в 3 раза больше лидов»

Гарантировать утроение заявок нельзя: результат зависит от трафика, оффера, цены и скорости работы менеджеров. Макет собирает все рычаги, которые влияют на число заявок, а этот документ показывает, как проверить цель на ваших данных. Цифр «будет +200%» здесь нет, потому что у меня нет данных вашей Метрики и CRM.

**Арифметика цели.** Заявки = посетители × конверсия посетителя в заявку.
- Если трафик не растёт, утроение заявок значит рост конверсии с N% до 3N%. Например, с 0,8% до 2,4%.
- Если конверсия на сайте уже хорошая, придётся добавлять и трафик (SEO из отчёта №1, реклама, вебинары).
- Узнать N можно за 10 минут: Метрика → Конверсии → цели «отправка формы» и «клик по телефону» за последние 3 месяца, отдельно по десктопу и мобильным.

| Было (сайт сейчас) | Стало (макет №2) | Что это даёт |
|---|---|---|

| Одна длинная форма: имя, email, телефон, компания, число сотрудников, два чекбокса | **Двухшаговая форма**: сначала один клик (число сотрудников), потом имя и телефон | Первый шаг ничего не стоит, дальше человек уже вовлечён. Меньше полей на втором шаге |
| Шесть разных названий кнопки (Заказать демо, Записаться на Демо, Получить демо-доступ, Оставить заявку, Обсудить с экспертом, Записаться на экскурсию) | **Одно главное действие: «Начать бесплатно»** (14 дней), везде одинаково | Один понятный шаг вместо выбора |
| Каждая кнопка ведёт на прокрутку или разные формы | **Любая кнопка открывает ту же форму в окне**, не уводя со страницы | Нет пути «нажал и потерялся» |
| Нет выбора отрасли, один текст для всех | **Переключатель отраслей** (рестораны, розница, гостиницы, клиники, логистика, франшизы): своя выгода и своя реальная цитата клиента, в заявку уходит отрасль | Релевантность растёт, менеджер сразу знает контекст |
| Нет инструмента вовлечения | **Калькулятор «Сколько вам стоит текучка»**: человек вводит свои цифры, видит сумму, и в заявку уходит результат расчёта | Лид-магнит с личной выгодой, тёплые заявки с готовым поводом для разговора |
| Телефон и Telegram только в шапке и подвале | **Телефон, часы работы, Telegram в верхней полосе**, **чат-помощник**, **мобильная панель** «Начать бесплатно / Позвонить / Telegram» | Больше способов обратиться без формы |
| Выход со страницы без попытки удержать | **Окно при уходе** (только десктоп, один раз): «Получите все ответы о работе платформы за 15 минут», только телефон | Ловит часть уходящих посетителей |
| Тарифы с кнопкой «Оставить заявку» | У каждого тарифа кнопка **«Попробовать 14 дней бесплатно»**, плюс «Подобрать тариф» | Меньше страха оплаты: сначала пробуют |
| Возражения (цена, пробный период, запуск, данные) спрятаны в конце длинного FAQ | **Короткий FAQ только с возражениями**, у ответов про цену и пробный период стоит кнопка | Снимаем сомнение в момент, когда оно возникает |
| Вебинары и награды в первых блоках | Награды сжаты в **ленту доверия** (400+ компаний, с 2015, реестр ПО № 13970, поддержка 3 часа, ФРИИ) сразу под первым экраном | Доверие без отдельного экрана |

### Порядок блоков
1. Верхняя полоса: часы работы, телефон, Telegram.
2. Первый экран: оффер + форма.
3. Лента доверия.
4. Выбор отрасли (персонализация).
5. Что вы получаете (4 результата по пути сотрудника).
6. Как работает: 3 шага и интерфейс приложения.
7. Калькулятор потерь.
8. Тарифы.
9. Кейсы + сервис-менеджер на аутсорсе.
10. Возражения (FAQ).
11. Финальный призыв: форма и альтернативные способы связи.
12. Подвал.
Поверх страницы: чат-помощник, мобильная панель, окно при уходе.

Что убрано с главной (оставить на отдельных страницах): технологический стек, свидетельство о регистрации программы, подборка публикаций в СМИ, длинные описания всех функций, десять кейсов. Эти блоки не помогают принять решение «оставить заявку» и удлиняют путь.

## План проверки цели (чтобы понять, достигнуто ли ×3)

1. **Нулевая точка (неделя 0).** Выгрузить за 3 месяца: визиты, заявки по формам, звонки, источники, устройства, конверсию по страницам. Записать в таблицу:

| Показатель | Сейчас | Цель (×3) |
|---|---|---|
| Визиты в месяц | | |
| Конверсия в заявку, десктоп | | |
| Конверсия в заявку, мобильные | | |
| Заявок в месяц | | ×3 |
| Доля заявок, дошедших до демо | | не ниже, чем сейчас |

2. **Разбить внедрение на шаги и проверять по одному** (A/B-тест, Яндекс Метрика Эксперименты или аналог):
   1. Форма в первом экране + единая кнопка.
   2. Двухшаговая форма против одношаговой.
   3. Переключатель отраслей.
   4. Калькулятор.
   5. Чат и мобильная панель.
   6. Окно при уходе.
   Для надёжного вывода нужен трафик: ориентир, около 300–500 заявок на вариант. При меньшем потоке тестируйте последовательно (до/после) на 2–4 неделях.

3. **Следить за качеством, а не только за количеством.** Больше заявок бесполезно, если доля дошедших до демо и оплаты упала. Считать по каждой заявке: источник, форма, отрасль, дошла ли до демо, до сделки.

4. **Скорость ответа.** Завести правило: первое касание в рабочее время за 15 минут. Это бесплатно и сильно влияет на результат, но без него остальные улучшения теряют эффект.

5. **Параллельно растить трафик.** Если конверсия вырастет в 1,5–2 раза, оставшийся рост даст SEO (отчёт №1), вебинары и реклама на страницы отраслей. Макет подготовлен под это: страницы отраслей получают свои заявки с пометкой отрасли.

## Что нужно вам решить до запуска

1. **Цена.** На сайте две версии: в FAQ «от 170 ₽ за пользователя в месяц», в тарифах «от 59 990 ₽ для команд от 30 сотрудников». В макете использованы тарифы. Нужно привести всё к одной версии, иначе падает доверие.
2. **Метрика карточки Tegen.** В макете стоит слово «Выбрали», потому что цифры у кейса нет. Если есть реальный результат, добавьте его.
3. **Обещание по скорости.** В макете: «ответим в рабочее время, ежедневно 10:00–19:00» (это факт с сайта). Если сможете гарантировать «перезвоним за 15 минут», это усилит форму, но только при реальном выполнении.
4. **Окно при уходе и чат.** Убедитесь, что они вас устраивают по тону. На мобильных окно при уходе не показывается.
5. **Каналы.** В макете Telegram-бот поддержки, звонок и email. WhatsApp и MAX можно добавить через Wazzup (подключён) после решения, кто их ведёт.
6. **Интеграция форм.** В макете формы ничего не отправляют. В боевом варианте каждая заявка должна идти в amoCRM со скрытыми полями: источник, UTM, страница, отрасль, число сотрудников, результат калькулятора. В коде макета место для этого отмечено комментарием.
7. **Юридическая часть.** Текст согласия оставлен как на сайте (обязательное согласие, рекламное необязательное). Проверьте с юристом вариант для двухшаговой формы и окна при уходе.

## Чем макет №2 отличается от макета №1

| | Макет №1 (визуальный) | Макет №2 (конверсионный) |
|---|---|---|
| Цель | Показать технологичность и дизайн | Собрать заявки |
| Тексты | Как на сайте | Переписаны под выгоду и действие, только факты с сайта |
| Тема по умолчанию | Тёмная, «центр управления» | Светлая, контрастная, акцент на действии (лаймовая кнопка) |
| Форма | После нескольких экранов | В первом экране, двухшаговая, везде одна |
| Блоки | Все блоки сайта | Только то, что влияет на решение. Остальное уходит на отдельные страницы |
| Вовлечение | Интерактивный телефон | Выбор отрасли, калькулятор, чат |

Их можно объединить: визуальный язык макета №1 (тёмный первый экран, свечение, стеклянные карточки) и структуру макета №2 (форма, отрасли, калькулятор). Если захотите, соберу такой гибрид.
