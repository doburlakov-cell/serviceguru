# Платформа рассылки по Telegram (Vercel)

Вход по паролю, подключение Telegram-аккаунтов, рассылки с настройкой скорости, окна времени и лимитов.

## Как работает
- Vercel не держит постоянный процесс, поэтому рассылка идёт «тиками»: внешний cron раз в минуту вызывает `/api/tick`.
- В каждом тике каждый аккаунт отправляет не больше `сообщений в минуту`, с равными паузами внутри минуты.
- Сессии Telegram лежат в Postgres в зашифрованном виде (ключ — `SECRET_KEY`).
- Один чат получает сообщение один раз за рассылку, даже если он есть у нескольких аккаунтов.

## Настройки рассылки
- сообщений в минуту на аккаунт (1–20);
- лимит в день на аккаунт и общее число контактов;
- окно отправки (часы) и часовой пояс;
- типы чатов, список исключений, пауза и возобновление.

## Развёртывание
1. Создайте базу Postgres (например, бесплатный Neon) и возьмите строку подключения.
2. В Vercel: New Project → этот репозиторий → **Root Directory = `broadcast_app`**.
3. Переменные окружения:
   - `APP_PASSWORD` — пароль входа;
   - `SECRET_KEY` — длинная случайная строка (после запуска не менять, иначе сессии не расшифруются);
   - `CRON_SECRET` — длинная случайная строка (Vercel сам подставит её в заголовок cron-запроса);
   - `DATABASE_URL` — строка подключения Postgres.
4. Vercel Hobby не поддерживает cron чаще раза в сутки, поэтому `/api/tick` вызывает внешний сервис
   (например, cron-job.org) каждую минуту: `https://<ваш-домен>/api/tick`, заголовок
   `Authorization: Bearer <CRON_SECRET>`. На Vercel Pro можно добавить в `vercel.json`
   `"crons": [{"path": "/api/tick", "schedule": "* * * * *"}]`.
5. Откройте сайт, войдите, добавьте аккаунт (api_id и api_hash — на my.telegram.org), введите код из Telegram,
   нажмите «Синхронизировать чаты», создайте рассылку и запустите.

## Важно
- Рассылка с пользовательских аккаунтов может приводить к ограничениям Telegram. Начните с малого лимита контактов.
- Лимит в минуту считается отдельно для каждой рассылки, поэтому не запускайте несколько рассылок на одном аккаунте одновременно.
